# Drift

Процедурный генератор фоновой музыки в браузере: бесконечный стрим в духе lo-fi / фэнтези / ретро-аниме радио. Всё синтезируется на лету через Web Audio API — без сэмплов, библиотек и сборки.

## Запуск

```bash
python3 serve.py
```

Открыть <http://localhost:8765/> и нажать «Играть» (или пробел). Сервер отдаёт файлы без кэширования, чтобы правки в коде были видны сразу.

## Что умеет

- **Темы**: Lo-fi, Фэнтези (таверна, баллада, плач, мистика, марш — стиль выбирается по настроению), Ретро-аниме, Эмбиент, Синтвейв.
- **Настроение**: весёлое, спокойное, грустное, таинственное, эпичное — меняет лад, темп, плотность, характер мелодии.
- **Сид задаёт весь трек**: тональность, лад, размер, темп, инструменты, состав слоёв, настройки звука и все ноты. Тот же сид — тот же трек.
- **Всё сочиняется по правилам**: готовых паттернов и сэмплов в коде нет — только жанровые вероятности.
  - *Гармония*: ход из двух фраз с каденцией, побочные доминанты, аккорды из параллельного лада, два аккорда в такте к концу фразы, органный пункт во вступлениях.
  - *Мелодия*: напев на 16 тактов из мотива и его развития (секвенция, обращение, контрастный мотив), с затактами, синкопами, вариацией при повторе и ответными репликами второго инструмента.
  - *Ритм-секция*: ударные на 4 такта со сбивками (малый или томы), шейкер, бас с подводками к следующему аккорду, перебор на 2 такта с акцентами.
  - *Динамика*: у секций разная сила исполнения, нарастание перед основной секцией, тарелка на её входе.
- **Бесконечный стрим**: «дирижёр» ведёт трек по секциям и главам; между главами меняются тональность, лад, темп, инструменты, материал и иногда размер.
- **Синтез**: пэды, хор (форманты), электропиано, флейта, струна Карплуса–Стронга (арфа, лютня, гитара, контрабас), вибрафон, шкатулка, синт-лид, чиптюн, три набора ударных, атмосферы (дождь, костёр, лес, волны, ночь), винил.
- **Размеры**: 4/4, 3/4, 5/4, 6/8, 9/8, 12/8.
- **Ручные правки**: любой параметр можно закрепить с панели; он действует на все следующие треки до «Сбросить правки».
- **Пауза и перемотка**: «Играть / Пауза» (пробел), ⏮ — в начало, шкала времени под спектром. Трек задан сидом вплоть до силы каждой ноты, поэтому перемотка работает и вперёд, и назад: дирижёр беззвучно проигрывается до нужного такта, и то же место всегда звучит одинаково. Шкала показывает первые 30 минут и растёт по мере игры.
- **Запись**: кнопка записи сохраняет звучащий поток в файл.

## Устройство

Состояние разделено на `settings` (выбор пользователя: сид, тема, настроение, громкость, ручные правки) и `track` (трек, целиком выведенный из сида). Правки накладываются поверх каждого нового трека.

- `src/theory.js` — лады, размеры, аккорды, генератор случайных чисел по сиду.
- `src/genres.js` — темы, настроения, характер ударных, секции стрима: только числа и пулы для выбора.
- `src/compose.js` — сочинение: профиль трека, гармония, мелодия, ударные, бас, аккомпанемент.
- `src/synth.js` — аудио-граф, эффекты, мастер-цепь и все голоса.
- `src/engine.js` — транспорт (пуск, пауза, перемотка), дирижёр и планировщик.
- `src/ui.js`, `index.html`, `style.css` — панель и визуализация.
- `analyze.js` — отладочный анализатор: рендерит трек офлайн и считает громкость слоёв, частотный баланс, клиппинг, ширину стерео и согласованность нот с аккордами. В приложение не подключён; в консоли страницы:

  ```js
  const s = document.createElement('script'); s.src = 'analyze.js'; document.head.append(s);
  await driftAnalyze(drift.settings, { seconds: 30 });
  ```

- `serve.py` — локальный сервер без кэширования.
