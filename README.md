# Drift

Процедурный генератор фоновой музыки в браузере: бесконечный стрим в духе lo-fi / фэнтези / ретро-аниме радио. Всё синтезируется на лету через Web Audio API — без сэмплов, библиотек и сборки.

## Запуск

```bash
python3 serve.py
```

Открыть <http://localhost:8765/> и нажать «Играть» (или пробел). Сервер отдаёт файлы без кэширования, чтобы правки в коде были видны сразу.

## Что умеет

- **Темы**: Lo-fi, Фэнтези, Ретро-аниме, Эмбиент, Синтвейв — у каждой свои инструменты, ударные и фоновая атмосфера.
- **Настроение**: весёлое, спокойное, грустное, таинственное, эпичное — меняет лад, темп, плотность, характер мелодии.
- **Бесконечный стрим**: «дирижёр» ведёт трек по секциям (вступление, основа, вариация, брейк…) и главам; между главами меняются тональность, лад, темп, инструменты и напев.
- **Инструменты**: пэды, хор (формантный синтез), электропиано, флейта, арфа и лютня (модель струны Карплуса–Стронга), музыкальная шкатулка, синт-лид, чиптюн, несколько басов и наборов ударных.
- **Атмосфера**: дождь, костёр, лес с птицами, волны, ночь со сверчками, винил, «плёночное» плавание высоты.
- **Размеры** 4/4 и 12/8, запись в файл, сохранение настроек, сид для воспроизводимости.

## Файлы

- `engine.js` — движок: генерация аккордов, мелодии и паттернов, дирижёр, синтез всех голосов.
- `ui.js`, `index.html`, `style.css` — панель управления и визуализация.
- `analyze.js` — отладочный анализатор: рендерит трек офлайн и считает громкость слоёв, частотный баланс, клиппинг и согласованность мелодии с аккордами. В приложение не подключён; в консоли страницы:

  ```js
  const s = document.createElement('script'); s.src = 'analyze.js'; document.head.append(s);
  await driftAnalyze(drift.p, { seconds: 30 });
  ```

- `serve.py` — локальный сервер без кэширования.
